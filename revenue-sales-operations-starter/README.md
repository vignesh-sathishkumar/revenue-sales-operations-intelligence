# Revenue & Sales Operations Intelligence

An independent portfolio case study for a **fictional** B2B SaaS company, NexaCloud Solutions.

## Business objective
Analyze sales pipeline, conversion, revenue, forecast accuracy, and sales-cycle efficiency to propose evidence-based operational improvements.

## Research questions
1. Which products and regions contribute the most closed-won revenue?
2. Where are opportunities lost in the sales funnel?
3. How do win rates and cycle times vary by representative?
4. How accurate are monthly revenue forecasts?
5. Which operational interventions merit testing?

## Planned datasets
- customers.csv
- products.csv
- sales_reps.csv
- opportunities.csv
- activities.csv

All generated data will be synthetic. No confidential employer or customer information is used.

## Project roadmap
1. Define scope and set up repository
2. Generate synthetic datasets and data dictionary
3. Clean and validate in Excel
4. Load PostgreSQL and run SQL analysis
5. Define KPIs and calculations
6. Model data and create DAX measures
7. Build Power BI dashboard
8. Document findings and recommendations
9. Prepare business documentation
10. Publish and present portfolio
